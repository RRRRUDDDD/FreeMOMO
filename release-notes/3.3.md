### 新增与优化

- 优化墨墨背单词 5.6.00 的应用内防更新保护：升级分发、下载预检查、下载启动、重试和模型安装入口独立安装，不再依赖完整手动更新适配器一次性成功。
- 增加有界恢复机制：首次安装不完整时，在首次界面恢复及其一秒后各重试一次；已成功安装的入口不重复注册。
- 防更新状态与业务 Hook 成功提示分离，分别提示已安装、降级、不完整、未安装或版本不支持，便于判断实际保护状态。
- 改进故障日志，标明失败成员、注册阶段和异常类型，不记录业务参数或异常消息。
- APK 与 Zygisk 模块版本统一更新为 3.3。

### 修复

- 修复部分通知字段或手动更新回调不可用时，已验证的核心防更新入口也未能安装的问题。
- 修复安装失败及重试时的回调状态隔离和清理问题；回滚时先禁用回调，并在单个卸载失败后继续清理其余句柄。
- 修复 SecNeo 检测子进程异常退出后导致墨墨主进程退出的问题，保留原有精确指纹校验与主进程异常处理。

### 使用注意

- 应用内防更新仅覆盖墨墨主进程内已验证的更新入口，不能阻止三星应用商店、其他商店或系统安装服务更新 APK；请单独管理商店自动更新设置。
- 完整更新适配器启用后保留手动检查和主动升级；降级保护状态下，手动升级也可能暂时不可用。
- 请同时更新 `freemomo.apk` 与 `freemomo-zygisk.zip`，并在安装 Zygisk 模块后重启设备。
